# Run Focused or Cross-Reference Analysis

Use one narrow rubric when a full flow or surface analysis would add noise.

## Focus one dimension

Examples include:

- mobile navigation;
- error and recovery states;
- trust and verification;
- pricing presentation;
- onboarding progress;
- empty states;
- product comparison;
- content hierarchy;
- seller or buyer role separation;
- localization behavior;
- adaptation to the target product.

State the parent flow or surface when known. Do not repeat its entire analysis.

## Compare products fairly

For cross-reference work:

1. Define one shared actor, goal, lifecycle point, device, locale, and question.
2. Use the same evidence threshold and rubric for every product.
3. Mark missing or incomparable evidence explicitly.
4. Separate product difference from observation-environment difference.
5. Avoid ranking products with arbitrary scores unless the user supplies a meaningful scoring model.

Use a compact matrix:

| Criterion | Reference A | Reference B | Evidence gap or implication |
| --- | --- | --- | --- |

## Synthesize patterns

Identify:

- common patterns;
- meaningful divergences;
- constraints that explain divergence;
- anti-patterns or unresolved risks;
- target-product hypotheses worth adapting or testing.

Do not treat prevalence as proof of quality. A common pattern may reflect convention, legacy, monetization, or constraints absent from the target product.
