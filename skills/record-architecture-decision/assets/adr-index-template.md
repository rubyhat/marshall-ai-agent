# Architecture Decision Records

This index routes material architecture decisions. Current system structure
belongs in the owning architecture documentation; each ADR preserves the
context, options, rationale, consequences, and review triggers for one choice.

## Lifecycle

The names below are semantic states. Use the project-configured label mapped to
each state; `proposed` may be disabled.

- `proposed` — material decision is unresolved.
- `accepted` — decision currently governs its declared scope.
- `superseded` — a newer accepted ADR replaces the decision.
- `deprecated` — decision should not guide new work and has no accepted
  replacement yet.
- `rejected` — proposed direction was deliberately rejected and its rationale
  remains useful.

Material changes to an accepted ADR require a new superseding ADR. Minor
clarifications may update the existing record without changing its meaning.
