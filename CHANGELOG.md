# Changelog

Все значимые изменения Marshall AI Agent Skills фиксируются в этом файле.

`CHANGELOG.md` и `version.txt` обновляются через Release Please. До первого
релиза версия репозитория остаётся `0.0.0`; первый releasable commit с типом
`feat` подготовит Release PR для `v0.1.0`.

До выпуска `v1.0.0` набор имеет экспериментальный pre-1.0 статус: installation,
update и compatibility contract могут уточняться с обязательным описанием
изменений и migration path в release notes.
